Вход на сам сайт пока не включён: учётные записи можно завести заранее, а сотрудники начнут входить, когда подключим вход (доступ по VPN). Тогда каждый увидит только своих клиентов и сможет делать то, что разрешает его роль.

Первый администратор

Учётных записей ещё нет. Создайте свою — администратор заводит остальных сотрудников.

Вход в админ-панель

Забыли пароль — попросите другого администратора сбросить его. Если администратор один: в Ubuntu, в папке проекта, команда docker compose exec web python -m app.auth reset-password ЛОГИН.

Смените пароль

Что сможет делать сотрудник каждой роли, когда на сайте будет включён вход. Роль задаётся в карточке сотрудника; «Представление» — какое представление «Реестра конкурсов» NocoDB открывать ему по умолчанию.
