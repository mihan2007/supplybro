# История изменений SupplyBro

## 0.1.1 — 26.10.2026
- Кнопка «+ Новый конкурс» — рядом со списком конкурсов (раньше пункт был спрятан внутри списка).
- В форме нового конкурса можно сразу выбрать или перетащить тендерную документацию (файлы или архив):
  после «Создать конкурс» папка создаётся по шаблону «К---», конкурс выбирается, файлы ложатся
  в «Конкурсная документация» и сразу уходят в обработку.

## 0.1.0 — 26.10.2026 — этап 1: документы конкурса
- Блок «Документы» на странице конкурса: загрузка перетаскиванием (или выбором) в «Конкурсная документация» /
  «Разъяснения заказчика» папки конкурса в `Dropbox\Агент`; список файлов со статусами (текст извлечён /
  распознан / ошибка / ждёт обработки), числом страниц и пометками; просмотр извлечённого текста; скачивание файла;
  «Обработать заново». Файлы, положенные в папку вручную, обрабатываются при открытии конкурса.
- Обработчик документов — отдельный процесс `worker` (очередь задач в SQLite, `app/db.py`, `app/worker.py`).
- Подготовка без ИИ (`app/docs/`): распаковка архивов (`tools/extract_archive.py` — копия из старого проекта),
  конвертация `.doc/.xls/.rtf/.odt` через LibreOffice, текст из Word (с восстановлением автонумерации пунктов),
  Excel (построчно, объединённые ячейки), PDF (по страницам), распознавание сканов и картинок (Tesseract rus+eng),
  скрытый текст — отдельно, пометка ⚠ для фраз, обращённых к ИИ; тексты — в `AIExtract\text`, поисковый индекс (FTS5);
  повторно обрабатываются только изменённые файлы. Испорченные имена из архивов показываются исправленными.
- Список конкурсов: к записи NocoDB привязывается её папка (по внутреннему номеру); папки без записи в NocoDB —
  отдельной группой; при недоступности NocoDB папки всё равно показываются.
- «+ Новый конкурс»: папка «<номер> <заказчик и предмет>» по шаблону «К---» (или со стандартными подпапками),
  номер подставляется следующий по порядку. «Создать папку» — для записи NocoDB без папки.
- Сборка: в образ добавлены LibreOffice (без окна), Tesseract с русским языком, unrar; пакеты Debian — с зеркала
  `APT_MIRROR` (mirror.yandex.ru); прокси при сборке передаётся и для apt. Новые настройки `.env`: `TENDERS_DIR`, `APT_MIRROR`.
- `config/clients.json`: у клиента `tenders_folder` («Наша»).

## 0.0.6 — 26.10.2026

## 0.0.4 — 26.10.2026
- Автозагрузка: «Добавить в автозагрузку.bat» кладёт в папку автозагрузки Windows
  (`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`) файл «SupplyBro - автозапуск.bat»,
  который при входе запускает «Запустить SupplyBro.bat /autostart» свёрнутым. Откат —
  «Убрать из автозагрузки.bat» (удаляет этот файл).
- «Запустить SupplyBro.bat /autostart»: без вопросов и без открытия браузера; программу-прокси
  ждёт до 2 минут (она может запуститься позже), потом запускает сайт всё равно.

## 0.0.3 — 26.10.2026
- «Запустить SupplyBro.bat» — запуск двойным щелчком: Ubuntu, сборка и запуск сайта, проверка
  прокси Windows, ожидание ответа сайта, открытие в браузере. При первом запуске добавляет в
  `%USERPROFILE%\.wslconfig` раздел `[general]` с `instanceIdleTimeout=-1` (Ubuntu не выключается
  сама, сайт работает в фоне) и делает `wsl --shutdown`. Откат — удалить эти две строки из `.wslconfig`.
- «Остановить SupplyBro.bat» — `docker compose down`.
- `run.sh` ждёт до 30 секунд, пока после включения Ubuntu поднимется Docker.
- `.gitattributes`: файлы `.bat` хранятся с переводами строк Windows.

## 0.0.2 — 26.10.2026
- Страница конкурсов: выпадающие списки «Клиент → Юр. лицо → Конкурс».
  - Клиенты и их юр. лица — в `config/clients.json` (у клиента своя база NocoDB).
  - Конкурсы — из «Реестра конкурсов» NocoDB, сгруппированы по участнику. Участник берётся
    из колонки «Участник» (когда она появится в реестре) или из строки «Участник: … (ИНН …)»
    в «Перечне документов заявки»; остальные — в группе «Участник не указан».
- Карточка конкурса: шапка (номер, стадия, срок подачи, НМЦ, ссылки на процедуру и NocoDB)
  и поля выбранного представления реестра («Вся таблица», «Тендерный специалист», «Логист»…),
  вложения — ссылками на скачивание, пустые поля можно скрыть.
- Спецификация конкурса: таблица выбранного представления («Сбор цен», «Закупки», «Цены агента»…),
  «№» и «Наименование позиции» закреплены слева, длинный текст раскрывается по щелчку.
- Сайт только читает NocoDB. Ключ берётся из файла `NOCODB_TOKEN_FILE` (папка secrets
  текущего проекта) и подключается в контейнер только для чтения.
- Сеть: на этом компьютере контейнер работает в сети Ubuntu (`compose.local.yml`) и ходит
  в NocoDB через прокси Windows (`OUTBOUND_PROXY`); сайт по-прежнему виден только на 127.0.0.1.
- `run.sh` дописывает в `.env` новые настройки из `.env.example` и проверяет, что файл ключа на месте.

## 0.0.1 — 26.10.2026
- Каркас локального сайта: FastAPI в контейнере Docker, страница `/` и проверка `/health`.
- Сайт открывается только на этом компьютере (`127.0.0.1:8000`), из сети не виден.
- Папка данных — внутри Ubuntu (`DATA_DIR` в `.env`), подключается в контейнер как `/data`.
- Сборка и запуск — `run.sh`: образ собирается через прокси Windows (`BUILD_PROXY` в `.env`),
  потому что docker compose не даёт шагам сборки сеть Ubuntu без особого разрешения.
