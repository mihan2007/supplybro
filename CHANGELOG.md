# История изменений SupplyBro

## 0.5.2 — 28.10.2026 — зарубежный поиск, проверка предложений, перепроверка (этап поиска цен завершён)
- Зарубеж — полный набор запросов Шага 5.1g: голый артикул, бренд + артикул, английское название детали + бренд +
  артикул (перевод названий — одним вызовом DeepSeek Flash), eBay / Amazon (`site:`), AliExpress, «Preis», «price»,
  альтернативные артикулы. Выбор цен — сначала Германия, Китай, США, другие страны — если там меньше трёх.
  Белорусские, казахстанские и др. сайты (.by, .kz, .ua, .am …) — зарубеж, «руб.» на .by — белорусские рубли.
- Перепроверка (Шаг 5.1i): по артикулам, где по рынку меньше трёх цен, — второй проход другими запросами DeepSeek
  («артикул lang:ru», «купить», «kaufen», «价格», Alibaba / Made-in-China, «Preis lang:de», «price lang:en»), новые
  страницы, проверка, объединение запросов обоих проходов в пометке «РФ / Зарубеж: найдено N из 3 [запросы: …]».
  Итог на странице: «Перепроверка (Шаг 5.1i): N арт., добавлено цен: M; без цен остались № …».
- Проверка предложений (Haiku) по правилам Шага 5.1g: тот же артикул — тот же товар (списки совместимости магазинов
  не сверяются — они неполные; раньше отклонялись верные предложения); «нет» — деталь вместо узла (резинка ролика,
  шестерня, чип), набор вместо одной детали, снятый лот; оригинал или аналог (не оригинал) — отмечается.
  Цена — только подтверждённая моделью (раньше при пустой цене подставлялось число со страницы — например, порог
  бесплатной доставки). В «Примечание»: пересчёт за упаковку («на странице 2600 RUB → за 1 ед. 1300 RUB»), аналоги,
  сомнительные предложения (⚠ ссылка — причина).
- Ссылка цены — только https:// (как требует проверка Шага 5.1g); http-сайты после переадресации — по итоговому адресу.
- Цены дешевле 15 % НМЦ за единицу больше не берутся (было 2 %): так отсекаются пороги доставки и детали.
- Страницы, открытые DeepSeek, хранятся сутки — повторный поиск за них не платит.
- Проверено у Claude на К992 (документы К934, 43 позиции) с настоящими DeepSeek и Haiku и сверено с ценами агента
  в спецификации К934: Россия — 69 цен у 31 позиции (агент — 45 у 34), зарубеж — 69 цен у 31 позиции (агент — 14 у 13),
  `check_prices.py` — без замечаний; из выбранных цен 29 — аналоги (помечены). Позиции KIP (№ 36–43) без цен — как и
  у агента. Собственное открытие страниц в песочнице Claude закрыто — все страницы открывал DeepSeek, поэтому у
  пользователя (страницы открываются напрямую) ожидается не меньше. Стоимость: ≈ $0,6 поиск + ≈ $0,1 открытие страниц +
  ≈ $0,1 проверка ≈ $0,8–1 за конкурс на 42 артикула, 7–15 мин.

## 0.5.1 — 27.10.2026 — поиск цен через DeepSeek
- По решению пользователя основной поиск цен — DeepSeek Search API (запущен 17.10.2026; тот же ключ DeepSeek,
  `app/prices/dsearch.py`): до 50 результатов на запрос за ~1 с, $0,75 за 1000 запросов (≈ 0,06 ₽). Россия — набор
  запросов Шага 5.1g с локализацией «Россия», зарубеж — «артикул price / Preis / 价格 / kaufen / бренд + артикул»
  (фильтр языка `lang:` не ставится — на редких артикулах он отсекал нужные страницы). Проверено на артикулах К934:
  A0P0R74100 — больше 10 российских магазинов (Claude находил 2–3), DK-8350 «Preis» — 12 магазинов DE/AT.
  Оценка для К993 (42 артикула): поиск ≈ $0,3 + проверка ≈ $0,1 вместо ≈ $2,5 у веб-поиска Claude.
- Выбор на странице «Поиск»: DeepSeek (по умолчанию) / Яндекс (Россия) + DeepSeek (зарубеж) / DeepSeek + Яндекс
  (сравнить — в отчёте видно, кто нашёл подтверждённые цены). Галочка «срочно» — только когда выбран Яндекс.
  Веб-поиск Claude за рубежом выключен (`PRICES_CLAUDE_ABROAD=0`, можно включить).
- Страницы, которые программа сама не открыла или где не нашла цену, открывает DeepSeek Fetch (текст страницы;
  ≈ 0,06 ₽, до 4 на артикул и 150 за поиск), затем — встроенный браузер. Проверено: Ситилинк открывается, Ozon и eBay — нет.
- Рынок — по сайту (.ru / .рф — Россия; AliExpress, eBay, Amazon… — зарубеж), для сайтов .com / .net / .market — по валюте
  цены (рубли — Россия). Поддомены одного магазина (voronezh.xcom-shop.ru и xcom-shop.ru) — один продавец.
- Цена дороже НМЦ за единицу больше чем в 10 раз или дешевле 2 % НМЦ в цены не идёт (лот, деталь, другой товар) —
  отмечается в «Как искали» (`PRICES_MAX_RATIO`, `PRICES_MIN_RATIO`).
- Исправлено: цена из текста склеивалась с артикулом («A0P0R74100 2 470 ₽» → 741 002 470); «р.» — рубли.
- Проверку «тот ли товар» можно перевести на DeepSeek: `PRICES_JUDGE_MODEL=deepseek-flash` (по умолчанию Haiku).
- Страница: обработчики кнопок регистрировались заново при каждом обновлении блока анализа (были внутри функции
  переключения вкладок) — вынесены; кнопка «Искать цены» не отправляет повторных запросов.
- Новые настройки `.env`: `PRICES_SEARCH`, `PRICES_JUDGE_MODEL`, `PRICES_CLAUDE_ABROAD`, `PRICES_MAX_ABROAD_PAGES`,
  `PRICES_DS_FETCH_PER_ITEM`, `PRICES_DS_FETCH_PAGES`, `PRICES_MAX_RATIO`, `PRICES_MIN_RATIO`, `DEEPSEEK_SEARCH_COUNT`.
  Ключ Яндекса теперь не обязателен.

## 0.5.0 — 27.10.2026 — поиск цен
- Блок «Поиск цен» под анализом, кнопка «Искать цены» (галочки «за рубежом» и «срочно»). Цены ищутся по позициям
  анализа; одинаковые артикулы — один раз. Порядок задаёт код (`app/prices/run.py`), задача `prices` обработчика
  идёт отдельной очередью (своим потоком) и не задерживает подготовку и анализ других конкурсов.
- Россия — Yandex Search API (`app/prices/yandex.py`): обязательный набор запросов Шага 5.1g (голый артикул,
  варианты написания, бренд + артикул, название + артикул, «купить цена»…; не меньше 5 на артикул). По умолчанию —
  отложенный режим (≈ 0,03 ₽ за запрос; ждём до `PRICES_ASYNC_TIMEOUT_MIN` минут, недостающее — мгновенным),
  «срочно» — мгновенный (≈ 0,49 ₽). Ответы Яндекса хранятся сутки (повторный поиск не платит второй раз), номера
  отложенных операций — тоже (после перезапуска ждём их, а не спрашиваем заново). Avito не ищется (на паузе).
- Зарубеж — веб-поиск Claude (`app/prices/abroad.py`, до `PRICES_ABROAD_SEARCHES`=5 поисков на артикул, Германия /
  Китай / США; ≈ $0,05–0,06 за артикул). AliExpress / eBay / Amazon из выдачи Яндекса — тоже в «зарубеж».
- Страницы магазинов программа открывает сама (`fetch.py`: Россия — напрямую, зарубеж — через прокси; не больше 2
  запросов к одному сайту), цену берёт из разметки товара (`extract.py`: JSON-LD / microdata / meta, иначе из текста),
  проверяет, есть ли артикул на странице. Если цену рисует JavaScript — открывает страницу встроенным браузером
  Chromium (добавлен в Dockerfile, необязательный шаг сборки).
- Тот ли это товар и цена за 1 единицу позиции (упаковка → пересчёт, б/у, деталь вместо товара, другое исполнение) —
  решает Haiku по выжимке со страницы (`judge.py`, ≈ $0,002 за артикул); текст страниц — данные, а не инструкции.
- По каждому рынку — 3 самые низкие подтверждённые цены от разных сайтов со ссылками, зарубеж — в рублях по курсу
  ЦБ на сегодня (`fx.py`, без наценки), пересчёт записан в «Примечание». Меньше трёх — пометка
  «РФ: найдено N из 3 [запросы: «…» | …]» (Шаг 5.1g). Страницы, которые не открылись, в цены не идут — в «Примечание».
- Своя база цен (`history.py`): тот же артикул в прошлых спецификациях NocoDB — цены отдела закупок, рынков, агента;
  на странице — колонка «Своя база», в «Примечании» — «Прошлые цены: …». Таблицы читаются раз в 12 часов.
- `Позиции_и_цены.xlsx`: добавлены 18 колонок рынков (РФ, Avito, зарубеж: предложение / ссылка 1–3), как в
  спецификации NocoDB. После поиска — проверка `tools/check_prices.py` (скопирован из старого проекта без изменений).
- NocoDB: цены и «Примечание» записываются в строки спецификации (PATCH по Id), только если спецификацию создал сайт;
  в спецификации агента и чужих записей ничего не пишется (цены — в xlsx). Цены отдела закупок и агента не трогаются.
- Повторный анализ переносит найденные цены и пометки поиска в позиции с тем же № и той же маркой/моделью.
  Анализ и поиск цен одного конкурса одновременно не запускаются.
- На странице: таблица по артикулам — НМЦ за единицу, 3 цены Россия / зарубеж со ссылками, «Мин. к НМЦ» (%),
  своя база, как искали (запросы, сколько страниц открыто, какие не открылись); стоимость — Claude $ и Яндекс ₽;
  до запуска — оценка стоимости.
- Ключ Яндекса — `secrets/API_key_Yandex.txt` (`YANDEX_KEY_FILE` в `.env`); без него кнопка выключена.
  Новые настройки `.env`: `YANDEX_KEY_FILE`, `PRICES_MODEL`, `PRICES_ABROAD`, `PRICES_ABROAD_SEARCHES`,
  `PRICES_ASYNC_TIMEOUT_MIN`, `PRICES_MAX_PAGES`, `PRICES_HISTORY_HOURS`, `YANDEX_RESULTS_PER_QUERY`.
- Проверено у Claude: Яндекс и страницы магазинов — подменой (сеть песочницы закрыта), зарубежный поиск Claude
  и проверка Haiku — настоящие (DK-8350: 8 немецких магазинов 141–204 €; A0P0R74100: США 58–100 $); 5 позиций К934 —
  ≈ $0,12, `check_prices.py` без замечаний; встроенный браузер — на странице с ценой из JavaScript.

## 0.4.0 — 27.10.2026 — стоимость, Haiku, запасной DeepSeek
- Стоимость в долларах: у анализа (в заголовке блока и по моделям под результатом) и под каждым ответом чата.

  по умолчанию — `claude-haiku-5-5` (`CLAUDE_MODEL`, список — `ANALYSIS_MODELS`). Проверка на К934: Haiku — 97 с,

- Для Haiku своя глубина размышлений `HAIKU_EFFORT=low`: при `medium` ответы не помещались даже в 40 тыс. токенов.

- Если на счёте Anthropic закончились деньги — анализ и чат продолжаются на DeepSeek (`FALLBACK_TO_DEEPSEEK=1`,
  `FALLBACK_DEEPSEEK_MODEL=deepseek-flash`); на странице это отмечено. Проверено подменой ошибки: анализ К934 на
  DeepSeek Flash — 73 с, ≈ $0.06, поля и 43 позиции на месте; чат отвечает DeepSeek с пометкой.
- Чат: результаты анализа в запросе — кратко (поля и проверки, без позиций), чтобы запрос к Haiku не превышал
  100 тыс. токенов (К934: было 103 тыс. → первый вопрос $0.10; стало 98 тыс. → вопрос ≈ $0.001–0.02).

## 0.3.0 — 27.10.2026 — чат по документации
- Блок «Вопросы по документации» под анализом: вопрос — ответ печатается по мере готовности; ответы только
  по документам конкурса и результатам анализа, в конце — «Источники:» с дословными цитатами, программа сверяет
  цитаты с текстом документов (✓ / ✗). Если ответа нет — «В документах не найдено». История — по каждому конкурсу
  (таблица `chat_messages` базы сайта), кнопка «Очистить». Под ответом — модель, токены, время.
- Экономия токенов: документы передаются одним блоком с меткой кэша Anthropic на 1 час (`CHAT_CACHE_TTL`);
  следующие вопросы читают их из кэша (~10 % цены), каждое обращение продлевает кэш; результаты анализа и история
  переписки — тоже из кэша. У DeepSeek кэш включается сам (проверено: из 79 589 токенов 78 848 — из кэша).
  Если документы не помещаются в лимит (`CHAT_MAX_CHARS`) — отправляются найденные фрагменты (индекс этапа 1).
- Модель — выбор на странице (запоминается в браузере): `claude-haiku-5-5` (по умолчанию), `claude-sonnet-5-5`,
  `deepseek-flash` (`CHAT_MODEL`, `CHAT_MODELS` в `.env`). Если API не примет кэш на час — повтор с кэшем на 5 минут.
- Понятные ошибки API: «на счёте Claude закончились деньги — пополните баланс (console.anthropic.com → Plans & Billing)».
- Сайту (сервис `web`) подключены ключи Claude и DeepSeek (только для чтения) — для чата.
- Новые настройки `.env`: `CHAT_MODEL`, `CHAT_MODELS`, `CHAT_CACHE_TTL`.
