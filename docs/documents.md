# Документы и папки конкурсов

Подробное описание для Claude. Перенесено из `CLAUDE.md` 28.11.2026 (0.45.5) без пересказа. Пункты с номером версии — как было сделано тогда; если два пункта противоречат друг другу, верен более поздний.

## Подготовка документов

- `app/docs/` — подготовка документов без ИИ: `pipeline.py` (порядок шагов), `extract.py` (текст из Word/Excel/PDF/картинок,
  автонумерация Word, скрытый текст, пометки обращений к ИИ; `EXTRACTOR_VERSION` — при изменении правил увеличить),
  `convert.py` (LibreOffice), `names.py` (исправление имён «Па®ЂЃ¶•≠®•» → «Приложение» только для показа).

## Папки конкурсов

- `app/tenders.py` — папки конкурсов в `Dropbox\Агент` (`TENDERS_DIR` → `/tenders` в контейнере), шаблон «К---».
  Документы конкурса (`doc_roots`) — `DOC_SUBFOLDERS` и папки `CHANGES_FOLDER_RE` («Изменения …», 0.9.0); без
  подпапок — вся папка.
  Новый конкурс: копия шаблона без AIExtract и без папок, где внутри AIExtract (материалы чужого конкурса —
  28.10.2026 в шаблоне «Наша\К---» лежала Documents_32616424721), плюс всегда `DOC_SUBFOLDERS` — иначе
  `doc_roots` берёт всю папку (так у старых папок без подпапок).
- Смена внутреннего номера конкурса (0.34.0, `app/tender_rename.py`; пользователь 25.11.2026, выбрано «К-номер
  везде»): кнопка `#head-rename` «✎ номер» в шапке (`.need-upload`, скрыта без номера) → `#rn-dlg` →
  `POST /api/clients/{id}/rename` {tender: Id реестра | «f:<папка>», number} (право upload). Проверки: номер не занят
  папкой / записью реестра (`_internal_variants`) / таблицей базы, нет задач queued/running/paused по папке. Шаги с
  откатом: папка (`os.rename`, имя — новый номер + прежний хвост) → PATCH «Внутренний номер» (+ «Ссылка на
  спецификацию» на таблицу своей базы, если вела в чужую) → таблица спецификации (`PATCH /meta/tables/{id}` с
  `title` и `table_name`, только если название = номер) → app.db одной транзакцией (`DB_TABLES`) → analysis.json.
  Кэши сайта сбрасываются (`_forget_caches`). `mail_inbox.match` принимает метку, сохранённую у запроса (старые письма).
